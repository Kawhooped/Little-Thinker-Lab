Mosslight — Laughing Overflow v0.2

This page documents the two complete assets that belong in this repository. The original self-contained HTML bundle contains both files as embedded Base64 data and can be used to download them.

  • training_data.jsonl — training corpus; destination: data/mosslight/training_data.jsonl
  • littlethinker_overflow.pt — trained model weights; destination: models/laughing-overflow/littlethinker_overflow.pt

To import the files, download and open the original littlethinker_lab_assets.html bundle, save both assets, then run scripts/import_full_package.sh with the extracted asset folder.
